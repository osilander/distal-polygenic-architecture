# omnigenic-model
Post-processing pipeline for all figures in the directional coherence / omnigenic manuscript.
Scripts are run from the project root (`omnigenic-model/`).
> **Repo intent:** code and figures release. `figures/` (PDF outputs) are tracked. `data/` and `results/` are not included — `data/` requires access to the source GWAS summary statistics, and `results/` must be generated by running the pipeline in order.
---
## Quick build-status check
```r
Rscript post-process-scripts/check-build-status.R
```
Verifies data symlink, HPC inputs, intermediate results, and reports what can and cannot be built.
---
## Build tiers
| Tier | What it covers | Requirement |
|------|----------------|-------------|
| **Fully local** | All figure scripts (run-figure\*.R, run-figureS\*.R) and downstream summaries | `results/` intermediates generated by running earlier steps |
| **Local if windows available** | Step 0 matrix build; FigureS1, FigureS8, FigureS11 | `data/windows_filtered/` via `data/` symlink |
| **Blocked — import HPC outputs** | Figure 1 scree panel; FigureS12 | `svd-nulls-50k/`, `chunk_withinperm_scree_runs_50k.tsv.gz`, `allbyall_cosine_matrices/` copied from source repo |
The machine-readable dependency graph is in `manifest.tsv` (columns: output, generator, key\_inputs, tier, used\_by).
---
## Directory structure
```
omnigenic-model/
  data/                    → symlink to ../directional-coherence/data/ (read-only)
  results/                 → generated outputs
  figures/                 → figure PDFs
  post-process-scripts/    → R scripts
  manifest.tsv             → machine-readable dependency manifest
  README.md
```
> **`data/` symlink:** this repo assumes `data/` points to the source manuscript data tree at `../directional-coherence/data/`. Set it up with:
> ```bash
> ln -s ../directional-coherence/data data
> ```

## HPC-imported inputs (†)
The following are HPC-generated null-permutation outputs that must be copied from the source repo. The scripts that consume them are present here; only the raw null runs themselves are not re-run locally.
| File | Used by | Source |
|------|---------|--------|
| `svd-nulls-50k/` | `compute-figure2-cache.R`, `run-allbyall-cosine-matrices.R`, `run-entrysign-perm-procrustes-normalized.R` | HPC run of `generate-svd-nulls-50k.R` |
| `chunk-withinperm-nulls-50k/chunk_withinperm_scree_runs_50k.tsv.gz` | `compute-figure2-cache.R` | HPC run of `analyse-chunk-withinperm-nulls-50k.R` |
| `allbyall_cosine_matrices/` | FigureS12 | Output of `run-allbyall-cosine-matrices.R` + `run-entrysign-perm-procrustes-normalized.R` on HPC |
Copy from `../directional-coherence/results/` (and `../directional-coherence/chunk-withinperm-upload-bundle/`) if rebuilding from scratch.

## Full build order
Scripts must be run from the **project root** (`omnigenic-model/`). Listed in dependency order.
### Step 0 — Build all trait × window matrices
```r
Rscript post-process-scripts/build-all-trait-matrices.R
```
Reads `data/windows_filtered/*_w*.summary.tsv` (via `data/` symlink) and writes
`results/all-trait-{25k,50k,100k,200k,500k,1m,...}-mean-{effects,pvals,rand-mean-effects}.tsv`
for every window size present. ---
### Step 1 — Pre-compute trait-PC category permutation table (needed by Figure 1)
```r
Rscript post-process-scripts/compute-trait-pc-category-labelperm.R
```
**Outputs:** `results/trait_pc_category_absrho_labelperm_pc1_pc14.tsv`,
`figures/figureS4_trait_pc_category_absrho_labelperm_pc1_pc14.pdf`
**Requires:** Step 0 complete, `results/pca_loadings_50k.tsv`.
**Appearance:** tiles filled by median |ρ| (ag_Sunset palette, cap 0.2), median |ρ| value shown per tile, significance stars above; category colour strip on left. Matches Figure 1 heatmap style.
---
### Step 2 — 25k PCA (needed by FigureS10 and S12)
```r
Rscript post-process-scripts/run-pca-25k-min20-anchored.R
```
**Outputs:** `results/pca_multiscale_anchored/pca_traits_25k_anchored.tsv` + window loadings, scree, flips.
Also writes `results/all-trait-25k-mean-effects-snp20.tsv` (SNP≥20 filter).
**Requires:** Step 0 complete.
---
### Step 3 — GWAS-removed distance analyses (needed by Figures 3, S13, S18–S23)
```r
Rscript post-process-scripts/compute-gwas-removed-distances.R 100   # ~45 min
Rscript post-process-scripts/compute-gwas-removed-distances.R 150   # ~45 min
Rscript post-process-scripts/compute-gwas-removed-cdf-ribbon.R
```
---
### Step 4 — SVD null permutations (needed by Figure 1 scree, FigureS12)
These are HPC-generated. Copy from the source repo rather than re-running locally.
If re-running is needed:
```bash
# Part A: SVD nulls (trait_flip, entry_flip, withinblock_perm — 100 iters each)
Rscript post-process-scripts/generate-svd-nulls-50k.R 100   # ~3–4 hr on laptop
# Part B: Chunked within-permutation nulls
Rscript post-process-scripts/prepare-chunk-withinperm-base-50k.R   # ~1 min
Rscript post-process-scripts/analyse-chunk-withinperm-nulls-50k.R 100   # ~2–3 hr on laptop
```
**Outputs:** `results/svd-nulls-50k/`, `results/chunk-withinperm-nulls-50k/chunk_withinperm_scree_runs_50k.tsv.gz`
---
### Step 5 — Figure 1 scree cache (needed by Figure 1)
```r
Rscript post-process-scripts/compute-figure2-cache.R
```
**Outputs:** `results/figure2_cache_50k.rds`
**Requires:** Step 0 complete, Step 4 outputs present.
---
### Step 6 — All-by-all cosine / Procrustes matrices (needed by FigureS12)
These are HPC-generated. Copy from the source repo rather than re-running locally.
If re-running is needed:
```bash
Rscript post-process-scripts/run-allbyall-cosine-matrices.R           # ~15 min
Rscript post-process-scripts/run-entrysign-perm-procrustes-normalized.R   # ~60–90 min on laptop
```
**Outputs:** `results/allbyall_cosine_matrices/`
**Requires:** Steps 0, 2, 3, 4 complete; FigureS8 and FigureS9 complete.

### FigureS2 — SVD robustness checks
```r
Rscript post-process-scripts/run-figureS2.R
```
**Outputs:** `figures/figureS2_robustness_checks.pdf`
**Requires:** `results/svd_robustness/*.tsv` (from `compute-svd-robustness.R`).
**Appearance:** Five-panel figure. (a) Per-PC cosine similarity to original decomposition across 100 random and stratified 2/3 trait subsampling replicates. (b) Procrustes similarity for trait subsampling (k = 4, 8). (c) Per-PC cosine similarity for 100 window subsampling replicates on the full and GWAS-depleted matrices. (d) Procrustes similarity for window subsampling. (e) Leave-one-category-out cosine similarity for PC1–PC8, sorted by PC1 disruption; observed values colour-coded using the ag_Sunset palette (warm = low cosine = structurally important category); grey bars show size-matched null (30 replicates, median + 95% interval).
To recompute the robustness TSVs from scratch:
